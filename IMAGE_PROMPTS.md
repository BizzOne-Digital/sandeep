## Image Optimization Notes

- **Format:** Use WebP for web delivery, JPEG as fallback
- **Sizes needed:**
  - Desktop: 1920px, 1200px, 800px widths
  - Tablet: 768px, 600px widths  
  - Mobile: 480px, 320px widths
- **Compression:** Optimize all images to <200KB per image
- **Alt text:** Add descriptive alt text for accessibility
- **Lazy loading:** Implement for images below fold
